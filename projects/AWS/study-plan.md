# 📘 Study Plan — AWS Certified AI Practitioner (AIF-C01)

A 4-week plan to prepare for the AI Practitioner exam.

| Week | Focus | Key topics |
|:----:|-------|------------|
| **1** | Fundamentals | Read exam guide; refresh cloud basics; distinguish AI / ML / Deep Learning / GenAI |
| **2** | Core concepts | Types of ML; AWS AI services (SageMaker, Bedrock, Q, Rekognition, Comprehend); GenAI (foundation models, prompting, RAG, fine-tuning) |
| **3** | Responsible AI & depth | Bias, fairness, explainability; security & governance; practice questions → note gaps |
| **4** | Simulation & polish | Official pretest under real conditions; review wrong answers; schedule the exam |
