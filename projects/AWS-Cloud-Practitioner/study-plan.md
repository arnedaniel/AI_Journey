# Study Plan — AWS Certified Cloud Practitioner (CLF-C02)

The exam attempt is valid until **30 November 2026**. The plan runs towards that date, next to a full semester, so it is built around something I can do in short sessions rather than long ones.

---

### <a name="leaf-1"><img src="../../assets/leaves/leaf-1.svg" width="16" alt=""></a> &nbsp;What the deck is made of

**Cloud Practitioner Essentials**, all thirteen modules, from the introduction to the cloud to well-architected solutions.<br>
**The four domain reviews**, one per exam domain, with the worked practice questions that come with them.<br>
**The exam guide**, as the checklist: the deck is sorted by its nineteen task statements, and each card names the one it belongs to.

### <a name="leaf-2"><img src="../../assets/leaves/leaf-2.svg" width="16" alt=""></a> &nbsp;Where the course is behind AWS

Building the deck turned up places where the course teaches an older state than AWS's own documentation. The cards teach the current one and name the old one beside it, because older practice questions still use it.

**S3 objects** go up to 50 TB, not 5.<br>
**The support plans** have new names and a new line-up; the course still teaches the old five.<br>
**Operational excellence** has eight design principles today, the review lists five.<br>
**Several services** have been retired, renamed or closed to new customers since the course was recorded.

The lesson is the same one the AI Practitioner taught me from the other side: the course is a source, not the reference.

### <a name="leaf-3"><img src="../../assets/leaves/leaf-3.svg" width="16" alt=""></a> &nbsp;The date

The attempt runs until **30 November 2026**. The exam gets booked once the cards sit, not before.

### <a name="leaf-4"><img src="../../assets/leaves/leaf-end.svg" width="16" alt=""></a> &nbsp;What is deliberately not in here

**No second pass through the videos.** The deck is the condensed version of them.<br>
**No published deck.** It is built from AWS training material and stays private.<br>
**No daily hour count.** Cards studied and topics covered say more than minutes logged.
