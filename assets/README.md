# assets

Two files, both hand-written SVG.

`rail.svg` — the gradient bar at the top of every page in this repository, except the root.

`journey-map.svg` — the map at the top of the root page. A chip in the centre, one card per
project, traces between them with electrons running along the live ones. A project with work in
it gets a coloured card and a live line; one not started gets a grey card on a dashed line.

One card carries a number: the Claude Masterclass lesson count. It has to be edited by hand
when that count moves, and it is the only thing here that can go out of date.

Both live here, in the repo, on purpose. A badge service or an image host would mean a third
party gets a request, and a log entry, every time someone opens one of these pages. This way
the page asks nothing of anyone.

Nothing else belongs in this folder.
