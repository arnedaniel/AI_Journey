# assets

One file: `rail.svg` — the gradient bar at the top of every page in this repository.

It lives here, in the repo, on purpose. A badge service or an image host would mean a third
party gets a request, and a log entry, every time someone opens one of these pages. This way
the page asks nothing of anyone. It is hand-made, carries no numbers, and never goes stale.

Nothing else belongs in this folder.
